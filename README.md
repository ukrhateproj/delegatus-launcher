# Delegatus Launcher

Неофіційний запускатор Delegatus для **macOS і Windows**. Відкриває Delegatus
в окремому вікні, знаходить сумісні залежності та допомагає встановити відсутні
в приватну папку користувача.

Current version: **2.0.1 for macOS and Windows.**

## Завантаження

Готовий універсальний ZIP-архів поширюється окремо. Повністю розпакуйте його
перед запуском. Цей репозиторій містить вихідний код, скрипти повторної збірки
та готовий Windows-запускатор у папці `Windows/`.

- **Mac:** перетягніть `Delegatus.app` до «Програми» й відкрийте. Потрібна macOS 13+.
- **Windows:** відкрийте `Delegatus.exe`. Папка `Resources` має залишатися поруч.
  Потрібні 64-бітна Windows 10 1809+/11, .NET Framework 4.7.2+ і Edge або Chrome.

Під час першого налаштування користувач явно підтверджує завантаження Bun 1.4.3
та Delegatus 1.11.0. Контрольна сума архіву Bun перевіряється. Наявні глобальні
інсталяції та shell profiles не замінюються. Для агентних задач користувач
підключає власний Codex або Claude Code.

## Що є в запускаторі

- Окреме вікно Delegatus та іконка програми.
- Повторне використання здорового сервера на `127.0.0.1:8898`.
- Журнали, видимі помилки та підтвердження перед звільненням зайнятого порту.
- Приватне встановлення залежностей і можливість вибрати їх вручну.
- Both launchers in 2.0.1 include a persistent “Do not show again” option for the
  already-running information notice. Installation, cancellation and stop
  confirmations and error messages remain available.

## Стан перевірки

На Apple Silicon перевірені приватне перше встановлення, скасування без втрати
попередніх залежностей, 19 перевірок пошуку та налаштувань, запуск перенесеної
програми і збереження вибору галочки після перезапуску.

Mac-бінарник містить `arm64` і `x86_64`; запуск на фізичному Intel Mac не
підтверджений. Windows EXE з іконкою скомпільовано; перевірено синтаксис PowerShell,
компіляцію допоміжного C# та обробку аргументів. **Фактичний запуск на Windows
поки не перевірений.** Докладні межі перевірки: [VALIDATION.json](VALIDATION.json).

Mac-програма має локальний ad-hoc підпис без Apple notarization. Windows EXE не
має Authenticode-підпису. Система отримувача може попередити або заблокувати
перше відкриття; пояснення наведені в інструкціях.
