Delegatus Launcher 2.0.1 — для Mac

Це неофіційний запускатор відкритого Delegatus. Його можна передавати іншим
користувачам: у програмі немає особистих шляхів, журналів, проєктів або акаунтів.
Для Windows використовуйте окрему папку Windows з універсального архіву.

Вимоги: macOS 13 або новіша; Mac з Apple Silicon або Intel. Під час першого
встановлення залежностей потрібен інтернет. Програма містить обидві архітектури.
Фактичний запуск перевірено на Apple Silicon; Intel збірку скомпільовано,
але на фізичному Intel Mac не запускали.

Як користуватися
1. Розпакуйте архів і перетягніть Delegatus.app до «Програми» або ~/Applications.
2. Відкрийте Delegatus.app. За бажанням закріпіть його іконку в Dock.
3. Якщо Bun і Delegatus уже є, запускатор спробує використати їх.
4. Якщо залежностей бракує, натисніть «Установити залежності» у налаштуванні.
   Будуть завантажені Bun 1.4.3 з офіційного GitHub oven-sh/bun та
   delegatus-cli 1.11.0 з npm. SHA256 архіву Bun перевіряється перед запуском.
   Перед завантаженням програма показує, що буде встановлено і куди.
   Також можна вибрати власні файли Bun та Delegatus вручну.
5. У відкритому Delegatus підключіть свій Codex або Claude Code й оберіть
   папку проєкту. Акаунти та агентні CLI не передаються з цим архівом.
   Офіційна інструкція: https://github.com/Latand/delegatus#quick-start

Залежності, які встановлює запускатор, зберігаються лише для цього користувача:
~/Library/Application Support/Delegatus Launcher/Runtime
Він не замінює глобальну інсталяцію Bun або Delegatus і не змінює shell profiles.
Налаштування: ~/Library/Application Support/Delegatus Launcher/settings.json
Журнали: ~/Library/Application Support/Delegatus Launcher/Logs
Власні дані Delegatus зберігаються в його звичайних папках користувача.

Вікно та сервер
Сайт відкривається у власному вікні. Угорі доступні оновлення, журнал
і керування запуском. Cmd+W закриває вікно, залишаючи сервер працювати;
повторне натискання іконки показує те саме вікно. Cmd+Q завершує програму
і надсилає SIGTERM лише серверу, який вона сама створила. Наявний зовнішній
сервер на 127.0.0.1:8898 використовується без його зупинки при виході.
Якщо порт займає інша програма, «Звільнити порт» показує назву та PID
і просить підтвердження перед завершенням. «Скасувати» зберігає процес.

Перше відкриття та підпис
Ця збірка має локальний ad-hoc підпис; вона не має Developer ID і не пройшла
Apple notarization. Тому Mac отримувача може заблокувати перше відкриття.
Якщо ви довіряєте джерелу й перевірили архів, скористайтеся штатною
інструкцією Apple для такого випадку:
https://support.apple.com/en-us/102445
Захист macOS глобально вимикати не потрібно. Якщо Mac керується організацією,
її правила можуть не дозволити запуск такої програми.

Видалення
Завершіть запускатор і перемістіть Delegatus.app у Смітник. Приватну папку
Application Support/Delegatus Launcher можна окремо зберегти або видалити.
Це не видаляє акаунти чи проєкти самого Delegatus.

Ліцензії: дивіться LICENSE.txt та THIRD_PARTY_NOTICES.txt.
Тестові обмеження: Windows має окремий запускатор; фактичний запуск на
Windows або іншому фізичному Mac має перевірити отримувач.

Оновлення 2.0.1 для Mac: у поясненні «Delegatus уже працює» додано галочку
«Не показувати більше». Вибір зберігається для цього користувача між запусками.
Підтвердження встановлення й повідомлення про помилки залишаються доступними.
