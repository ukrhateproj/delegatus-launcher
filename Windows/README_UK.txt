ЗАПУСКАТОР DELEGATUS 2.0 — WINDOWS

Цю папку можна передавати іншим. Вона не містить особистих облікових записів,
історії чатів, API-ключів, cookies або встановлених Bun/Delegatus.

ВИМОГИ
- 64-бітна Windows 10 версії 1809 (збірка 17763) або новіша, чи Windows 11.
- x64 (Intel/AMD із SSE4.2) або Windows ARM64.
- Вбудований Windows PowerShell 5.1 та .NET Framework 4.7.2 або новіший
  (входить до Windows 10 1809 і новіших), стандартний WinForms.
- Microsoft Edge (рекомендовано) або Google Chrome для окремого вікна програми.
- Інтернет і вільне місце для першого встановлення залежностей. Уже наявні сумісні
  Bun і Delegatus можна використати без завантаження.
- Потрібен Bun 1.4.0+. Приватний установник фіксує Bun 1.4.3 і Delegatus 1.11.0.
  Для агентних можливостей може знадобитися окремий Codex/Claude CLI та вхід у нього.
  Цей запускатор не встановлює агентні CLI й не входить у їхні облікові записи.

ЯК ЗАПУСТИТИ
1. Розпакуйте всю папку у власний каталог. Resources має лишатися поруч із CMD.
2. Двічі натисніть Delegatus.exe — програму з іконкою. Права адміністратора не потрібні.
   Start Delegatus.cmd лишається додатковим консольним варіантом.
3. Якщо залежностей немає, натисніть Install і прочитайте точний опис встановлення.
   Завантаження почнеться лише після вашого Yes у вікні підтвердження.
   Choose Bun вибирає наявний bun.exe; Choose Delegatus — delegatus-cli/bin/cli.mjs.
4. Delegatus відкриється за адресою http://127.0.0.1:8898 в окремому app-вікні
   Edge/Chrome. Невелике вікно керування має кнопки Open Delegatus, Logs,
   Stop own server та Exit. Закриття app-вікна залишає сервер працювати.
   Exit дає вибір, зупинити власний сервер чи лишити його. Наявний чужий сервер
   запускатор не зупиняє. Під час встановлення й запуску є кнопка Cancel.
   Нижче описано клавіші додаткового консольного CMD-варіанта.

КЕРУВАННЯ
O — відкрити або підняти вже наявне вікно Delegatus.
L — відкрити папку журналів.
S — підтвердити завершення сервера, створеного цією консоллю, та його дочірніх процесів.
Q — вийти; для власного сервера можна вибрати, завершити його чи залишити працювати.
Закриття app-вікна не зупиняє сервер. Закриття консолі кнопкою X також може лишити
сервер працювати; використовуйте S або Q, щоб явно обрати поведінку.
Наступний запуск використовує вже готовий сервер і не завершує його як власний.
Повторне подвійне натискання передає сигнал наявній консолі й не запускає другий CLI.

ЗАВЕРШЕННЯ ПРОЦЕСІВ У WINDOWS
Для цього CLI у Windows немає Unix SIGTERM. S або Q→Yes застосовує taskkill лише
до перевіреного дерева власного сервера. Це може перервати активну роботу агентів;
перед дією з'являється відповідне попередження та підтвердження.
Якщо порт зайнятий, запускатор показує назву, PID і час запуску кожного власника.
Після окремого підтвердження він повторно перевіряє ці дані та завершує лише
погоджені процеси. Нові процеси автоматично не завершує, підвищення прав не запитує.

ДЕ ЗБЕРІГАЮТЬСЯ ФАЙЛИ
%LOCALAPPDATA%\Delegatus Launcher:
  Logs           Журнали запускатора, встановлення та stdout/stderr сервера.
  Runtime        Приватні Bun і локальні node_modules, без глобального встановлення.
  BrowserProfile Окремий локальний профіль Edge/Chrome і дані сайту.
  settings.json  Шляхи, вибрані чи встановлені у вашому обліковому записі Windows.
Сам Delegatus під час запуску може створювати свою звичайну користувацьку
конфігурацію, стан і посилання агентних skills. Вони не входять у цей пакет.
Запускатор не змінює постійний PATH, shell profiles, політику виконання PowerShell,
наявні глобальні пакети Bun/Delegatus або системні налаштування.
Cancel у вікні прогресу (або C у консольному варіанті) скасовує операцію. Часткові файли в приватному
Runtime і журнали можуть лишитися для діагностики. Наявні інсталяції не видаляються.
Для видалення спершу зупиніть власний сервер і закрийте його браузерне вікно, потім
видаліть цю розпаковану папку та власний каталог запускатора в LocalAppData.
Звичайний стан Delegatus збережіть за потреби. Спільні Bun/агентні інсталяції не чіпайте.

БЕЗПЕКА Й ПОМИЛКИ
Delegatus.exe та його PowerShell-ресурс не мають Authenticode-підпису.
Він не вимикає SmartScreen чи інші засоби захисту Windows. Перед використанням
можна переглянути Resources/Launch-Delegatus.ps1 і перевірити контрольні суми.
Якщо запуск блокує політика вашої організації, зверніться до адміністратора.
CMD передає власний шлях через змінну середовища та читає UTF-8 PowerShell-ресурс
як inline script block. Системна політика виконання не змінюється.
Програма показує помилки в окремому повідомленні. У додатковому CMD-варіанті
вони залишаються видимими в консолі; прочитайте їх перед натисканням клавіші.
Журнали можуть містити приватний вивід програми. Не додавайте журнали, settings або
BrowserProfile, коли передаєте пакет іншій людині.
Якщо Edge/Chrome немає, можна явно погодитися на звичайний браузер за замовчуванням.
Перед звільненням порту 8898 уважно перевірте назву процесу в підтвердженні.
Готовність перевіряється за HTML Delegatus і JavaScript з того самого сервера.

СТАН ПЕРЕВІРКИ
Підготовлено й статично переглянуто на macOS. На Windows пакет НЕ запускався;
підтвердження Windows end-to-end PASS немає. PowerShell 7.6.9 на Mac успішно
розібрав AST ресурсу; вбудовані C#-помічники компілюються цим інструментом.
Це не виконує API Windows. Для виробничого поширення потрібен
пробний запуск на справжній Windows: PowerShell 5.1, активація Win32-вікон,
скасування встановлення та поведінка процесів і файлових дескрипторів.
Під час підготовки Windows-пакета встановлення Bun/Delegatus не виконувалося.
